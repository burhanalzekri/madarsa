# مدرستي | MADRASA — الإصدار 0.28.0

منصة تعليمية عربية RTL مبنية على React/Vite وLaravel API وSQLite للتطوير المحلي. تحافظ على الهوية الخضراء والذهبية المعتمدة.

## ما الجديد في 0.28.0
- إعادة تصميم فعلية للوحة مدير المدرسة بمشهد حرم مدرسي ثلاثي الأبعاد مبني بـCSS، وبطاقات إحصاءات جديدة ولوحة مؤشرات تعليمية واختصارات مرئية.
- إعادة تصميم بوابة الطالب بمشهد تعلم ثلاثي الأبعاد من الكتب وغطاء التخرج، وأغلفة مقررات مختلفة، وعرض وحدات ودروس أكثر تنظيماً.
- تحسين الشريط الجانبي ورأس الصفحة وإبراز تسجيل الخروج.
- لا توجد تغييرات على قاعدة البيانات أو عقود API.
- تفاصيل الإصدار في `RELEASE_0.28.0_AR.md` وتعليمات التثبيت في `INSTALL_TERMUX_0.28.0_AR.md`.

## ما الجديد في 0.27.0
- إعادة تصميم لوحة مدير المدرسة بواجهة أكثر فخامة مع شريط تنقل أخضر داكن، وبطاقات مؤشرات ولوحة ترحيبية بتأثيرات عمق ثلاثية الأبعاد.
- إعادة تصميم بوابة الطالب بصرياً بأسلوب منصات التعلم المفتوح: لوحة تعلم شخصية، غلاف ثلاثي الأبعاد، بطاقات عائمة، تقدم واضح ومقررات بارزة.
- الحفاظ على الأخضر الداكن والذهبي والأبيض مع لمسات زمردية وخلفيات هادئة.
- تكبير الخطوط والمسافات في صفحات الطالب والإدارة وتحسين قابلية القراءة على الهاتف.
- إبراز تسجيل الخروج في رأس بوابة المدير ورأس بوابة الطالب، مع الاحتفاظ به في القائمة الجانبية.
- هذه دفعة تصميم وتجربة استخدام؛ لا تغيّر مخطط قاعدة البيانات أو صلاحيات API.

## ما الجديد في 0.26.0
- إضافة مركز تواصل للمعلم لإرسال إعلانات مرتبطة بالشعبة إلى الطلاب وأولياء الأمور.
- التحقق من إسناد المعلم للشعبة قبل النشر، مع عزل الإعلانات حسب المدرسة والشعبة.
- دعم التصنيف والنشر أو حفظ المسودة وتاريخ انتهاء الإعلان.
- تفاصيل التغييرات في `RELEASE_0.26.0_AR.md`.

## ما الجديد في 0.25.0
- إعادة تصميم بوابة المعلم مع ترحيب شخصي واختصارات للمقررات والجدول والاختبارات والحضور.
- تحسين وضوح الخط العربي وأحجام النصوص على جميع البوابات ولوحة الإدارة.
- إظهار زر «تسجيل الخروج» بوضوح مع أيقونة ونص في جميع الأدوار.
- تفاصيل التغييرات في `RELEASE_0.25.0_AR.md` وتعليمات Termux في `INSTALL_TERMUX_0.25.0_AR.md`.

## ما الجديد في 0.24.0
- استكمال التعلم من آخر درس بدأه الطالب، مع إظهار وقت آخر مشاهدة.
- أزرار للتنقل بين الدرس السابق والدرس التالي، وحفظ إكمال الدرس.
- تحسين إمكانية تحديث الواجب غير المصحح قبل الموعد النهائي.
- إضافة دروس وأنشطة وإعلانات تجريبية متعددة الفئات في بيئة local/testing.
- إضافة اختبارات لخصوصية الإعلانات وصلاحيات إدارة المدرسة.
- تفاصيل التغييرات في `RELEASE_0.24.0_AR.md` وتعليمات Termux في `INSTALL_TERMUX_0.24.0_AR.md`.

## ما الجديد في 0.17.0
- فصل تجربة الطالب والمعلم عن لوحة الإدارة؛ لا تظهر للطالب أو المعلم قوائم وإجراءات الإدارة.
- بوابة الطالب تعرض مقررات الصف والفصل الدراسي الحالي، وبطاقات اختيار المادة لعرض وحداتها ودروسها المنشورة، والواجبات والاختبارات والتقدم.
- إضافة جدول أسبوعي حقيقي للحصص يظهر للطالب حسب شعبته وللمعلم حسب الإسنادات.
- إضافة شاشة إدارة الجدول الأسبوعي للمدير، مع التحقق من ارتباط المعلم والمادة والشعبة ومنع تعارض أوقات المعلم أو الشعبة.
- بوابة المعلم تعرض المواد والشعب المسندة، الوحدات والدروس والموارد التعليمية، عدد الطلاب، وجدوله الأسبوعي، مع الاحتفاظ بأدوات الاختبارات والحضور والتصحيح.
- بيانات تجريبية متعددة المواد والجدول الأسبوعي تُضاف في بيئة local/testing فقط.

## إصلاح الاتصال وتسجيل الدخول
الإصدار السابق 0.16.0 عالج رسالة `Failed to fetch` عبر عنوان API نسبي وVite proxy. يحتفظ هذا الإصدار بالإصلاح. شغّل Laravel على المنفذ 8000 وVite على 5173.

## تشغيل Termux
اتبع `INSTALL_TERMUX_0.17.0_AR.md`. احتفظ بملف backend/.env وقاعدة البيانات الحالية. شغّل `php artisan migrate` ثم `php artisan db:seed --class=DatabaseSeeder` في بيئة التطوير لإضافة مواد وجدول العرض التجريبي. لا تشغّل seeder التجريبي على بيانات إنتاج.

## حسابات التطوير
بعد تهيئة قاعدة البيانات في بيئة `local` أو `testing`:

| الدور | البريد الإلكتروني | كلمة المرور |
|---|---|---|
| المدير | admin@madrasa.test | MadrasaDemo!2026 |
| المعلم | teacher@madrasa.test | MadrasaDemo!2026 |
| الطالب | student@madrasa.test | MadrasaDemo!2026 |

## حدود الاعتماد
تم فحص صياغة ملفات PHP وسلامة الأرشيف. لم يكتمل تنزيل حزم npm في بيئة التجهيز، لذلك لم يكتمل بناء React ولم تُشغّل اختبارات تكامل Laravel. نفّذ `npm install` و`npm run build` و`php artisan test` على Termux قبل اعتماد النسخة للإنتاج. لا تستخدم بيانات العرض في الإنتاج.

## الإصدار 0.19.0 — الواجهة التسويقية والترحيبية
- جعل الصفحة الافتتاحية العامة هي نقطة الدخول الافتراضية قبل تسجيل الدخول.
- إضافة تعريف بالمدرسة والخدمات والقيم التعليمية وقسم لماذا تختار المدرسة.
- معرض صور بفلاتر حسب المبنى والكادر والطلاب والملعب والمعامل والرحلات، مع معاينة مكبرة.
- إضافة أزرار تسجيل الدخول في الواجهة الرئيسية والتذييل، مع إبقاء توجيه المستخدم حسب دوره بعد المصادقة.
- إضافة أقسام بيانات التواصل والعنوان، وتوضيح مواضع إدخال البيانات الرسمية للمدرسة.
- تحسين الواجهة التسويقية للجوال وإضافة تحميل كسول لصور المعرض وبيانات وصفية لمحركات البحث.

**ملاحظة تخصيص مهمة:** الصور الحالية صور توضيحية عامة وليست صور المدرسة الفعلية. يجب استبدالها بصور المدرسة المعتمدة، وإدخال العنوان وأرقام التواصل من بيانات المدرسة قبل النشر العام. لم تتم إضافة تخزين إداري للمعرض أو بيانات التواصل في قاعدة البيانات ضمن هذه الدفعة.

## التثبيت للإصدار 0.19.0
اتبع `INSTALL_TERMUX_0.19.0_AR.md`. بعد تثبيت الاعتماديات نفّذ بناء الواجهة (`npm run build`) واختبارات Laravel (`php artisan test`). لا تُشغّل Seeder على قاعدة بيانات إنتاج. الصور وبيانات التواصل في الصفحة التسويقية تحتاج تخصيصاً ببيانات المدرسة الحقيقية.
