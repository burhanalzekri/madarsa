# منصة مدرستي MADRASA — الإصدار 0.37.0

منصة مدرسية عربية RTL بواجهة React/Vite وخادم Laravel API وقاعدة بيانات SQLite أو MySQL/MariaDB. تشمل أدوار مدير المدرسة والمعلم والطالب وولي الأمر.

## مكونات النظام الحالية
- المصادقة باستخدام Laravel Sanctum ورموز Bearer.
- إدارة ملفات الطلاب والمعلمين وأرشفتها.
- الهيكل الأكاديمي: المراحل والصفوف والسنوات والفصول والمواد.
- تسجيل الطلاب في الشعب وإدارة الإسنادات.
- بوابة المعلم: المقررات والدروس والموارد والواجبات والتسليمات والتصحيح والاختبارات والحضور والجدول والإعلانات.
- بوابة الطالب: المقررات والدروس والتقدم والواجبات والاختبارات والتقارير والإعلانات.
- بوابة ولي الأمر: الأبناء المرتبطون بالحساب والحضور والنتائج والواجبات والتقارير.
- دليل مستخدم تفاعلي مختلف بحسب صلاحية المستخدم.

## ابدأ من هنا
1. راجع `INSTALL_TERMUX_0.37.0_AR.md` للتثبيت والإعداد الأولي.
2. شغّل migrations دون seeding على قاعدة المدرسة.
3. أنشئ مدير المدرسة باستخدام `php artisan madrasa:create-admin`.
4. أكمل إعداد المدرسة، ثم أنشئ الهيكل الأكاديمي قبل إضافة التسجيلات والإسنادات.
5. شغّل فحوص `php artisan test` و`npm run build` على بيئة التشغيل قبل إدخال بيانات حقيقية.

## تنبيهات مهمة قبل الاستخدام المدرسي
- `DatabaseSeeder` مخصص لبيئات `local/testing` فقط؛ لا تستخدم بيانات العرض التجريبي في الإنتاج.
- وحدات محددة في لوحة الإدارة لا تزال محلية/تجريبية، ويظهر تنبيه داخل لوحة الإدارة يوضح حالة الربط. لا تحفظ فيها بيانات رسمية.
- إعدادات الهوية البصرية في لوحة الإدارة تحفظ محلياً في المتصفح حالياً، وليست إعدادات خادم.
- `CurrentSchool` يعمل وفق نموذج مدرسة واحدة في قاعدة البيانات الحالية. لا تستخدم قاعدة مشتركة لعدة مدارس قبل استكمال عزل المدارس وربط المدير بمدرسته واختبارات العزل.
- الحزمة لا تتضمن ملفات `vendor` أو `node_modules` أو ملف `.env` أو قاعدة بيانات فعلية.
- لم يكتمل بناء Vite أو تشغيل اختبارات Laravel في بيئة إعداد هذه الحزمة بسبب عدم توفر Composer وتعذر اكتمال تنزيل npm. يلزم إتمام ذلك قبل الإنتاج.
