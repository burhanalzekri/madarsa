# حالة Backend — MADRASA 0.38.0

- Laravel 12 API مع Sanctum ومجموعات صلاحيات منفصلة للإدارة والمعلم والطالب وولي الأمر.
- ملفات الطلاب والمعلمين، إنشاء الحسابات وتحديثها وأرشفتها، مع بحث وترقيم صفحات.
- استيراد الطلاب CSV مع معاينة وتحقق من الحقول والتكرار والشعبة، وتصدير CSV من قاعدة البيانات، وحفظ ملف المستخدم والملف الدراسي والتسجيل في معاملة قاعدة بيانات.
- تحديث تسجيل الطالب في الشعبة من نموذج الإدارة، مع التحقق من أن الشعبة تتبع المدرسة الحالية.
- إصلاح مسار تشفير كلمات المرور عند إنشاء الطلاب والمعلمين والمدير الأولي؛ cast `hashed` في نموذج User هو نقطة التشفير الوحيدة.
- إضافة أمر `madrasa:create-admin` لإنشاء حساب مدير أولي من CLI بكلمة مرور مخفية وتأكيدها.
- حصر بيانات Seeder التجريبية في بيئتي local/testing.
- توجد اختبارات Feature لمسار كلمة المرور ومعاينة واستيراد الطلاب؛ يلزم تشغيلها مع Composer وPDO SQLite على بيئة التثبيت.
- جميع ملفات PHP اجتازت `php -l` في بيئة إعداد 0.38.0.
- لم تشغل اختبارات Feature لعدم وجود Composer dependencies أو PDO SQLite في بيئة الإعداد.
- نموذج CurrentSchool الحالي يفترض قاعدة بيانات مدرسة واحدة؛ دعم عدة مدارس في قاعدة مشتركة يحتاج ربطاً صريحاً للمدير والمدرسة وعزل جميع الاستعلامات واختبارات منع الوصول المتبادل.
