# حالة Backend — MADRASA 0.37.0

- Laravel 12 API مع Sanctum ومجموعات صلاحيات منفصلة للإدارة والمعلم والطالب وولي الأمر.
- إصلاح مسار تشفير كلمات المرور عند إنشاء الطلاب والمعلمين والمدير الأولي؛ cast `hashed` في نموذج User هو نقطة التشفير الوحيدة.
- إضافة أمر `madrasa:create-admin` لإنشاء حساب مدير أولي من CLI بكلمة مرور مخفية وتأكيدها.
- حصر بيانات Seeder التجريبية في بيئتي local/testing.
- إضافة اختبار Feature لكلمة مرور المستخدم.
- جميع ملفات PHP اجتازت `php -l`.
- لم تشغل اختبارات Feature لعدم وجود Composer dependencies في بيئة الفحص.
- نموذج CurrentSchool الحالي يفترض قاعدة بيانات مدرسة واحدة؛ دعم عدة مدارس في قاعدة مشتركة يحتاج ربطاً صريحاً للمدير والمدرسة وعزل جميع الاستعلامات واختبارات منع الوصول المتبادل.
