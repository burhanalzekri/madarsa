# حالة Backend — MADRASA 0.21.0

- Laravel API مع Sanctum وفصل المسارات حسب الدور.
- بوابة المعلم تدعم إدارة الوحدات والدروس والواجبات والتسليمات والتصحيح وتقرير التقدم.
- تحققات الخادم تربط عمليات المعلم بملفه وبإسناد المادة والشعبة والمدرسة.
